# Definition of Done

Um item só é considerado pronto quando:

- [ ] O código foi escrito em C e compila sem erros
- [ ] A funcionalidade foi testada e funciona como descrito no requisito
- [ ] As validações do item foram testadas
- [ ] Os dados são gravados e lidos corretamente nos arquivos de texto
- [ ] O item passou pela coluna Test do quadro
- [ ] O código foi enviado ao repositório no GitHub
- [ ] A issue foi movida para a coluna Done
